# Screen-Match

##**Sobre o projeto**
O sistema simula uma plataforma de streaming, onde realizamos o gerenciamento de informações de filmes, como títulos, anos de lançamento e cálculo de avaliações.

##**Evolução e Objetivos**
O projeto está em fase de refatoração para resolver problemas comuns de códigos procedurais, tais como:

Dados dispersos em variáveis soltas e falta de centralização.
Dificuldade na padronização dos atributos necessários para um filme.
Falta de coesão entre os dados e os comportamentos (funções) que os manipulam.
O foco atual deste estudo é a implementação de classes para garantir uma melhor modelagem, organização e legibilidade do código, aplicando os fundamentos da Orientação a Objetos no PHP.
